* xlib.el

Extensions and additions for [[https://github.com/rejeep/f.el][f.el]], [[https://github.com/magnars/s.el][s.el]], [[https://github.com/Wilfred/ht.el][ht.el]], and [[https://github.com/magnars/dash.el][dash.el]], plus utility macros for hooks, timers, and code ergonomics.

* Installation

Not yet on MELPA. Requires Emacs 30.1 and the packages =f=, =s=, =ht=, and =dash=.

** With =package-vc= and =use-package=

#+BEGIN_SRC emacs-lisp
(use-package xlib
  :vc (:url "https://github.com/tychoish/xlib.el" :rev :newest)
  :demand t)
#+END_SRC

#+RESULTS:

=:vc= support requires Emacs 30. To pin a specific revision, replace =:newest= with a commit hash.

** Manually

Clone the repository and add it to your =load-path=:

#+BEGIN_SRC sh
git clone https://github.com/tychoish/xlib.el ~/path/to/xlib.el
#+END_SRC

#+BEGIN_SRC emacs-lisp
(add-to-list 'load-path "~/path/to/xlib.el")
(require 'xlib)
#+END_SRC

Flatten LIST by exactly one level, collecting nested list items into a single list. Unlike ‘-flatten’, which recurses fully, ‘-unwind’ only removes one layer of nesting.

*** ~-flat-map~ =(function sequence)=

‘-flat-map’ applies (maps) a function, which returns a list, to each item in a list. The lists that result from the map operation are then concatenated or joined. This provides a dash.el conforming API for the ‘mapcan’ operation.

*** ~--flat-map~ =(form input-list)=

‘--flat-map’ evaluates a form for very item in ‘input-list’ with the item bound to ‘it’. The form must return a list, and the returned lists are then concatenated or joined into a single flattened list. This provides a dash.el conforming API for the ‘mapcan’ operation.

This is the anaphoric counterpart to ‘-flat-map’.

*** ~-mapc~ =(function sequence)=

Apply FUNCTION to each element of SEQUENCE for side effects only. Unlike ‘mapcar’, don’t accumulate the results.  Return SEQUENCE. SEQUENCE may be a list, a vector, a bool-vector, or a string.

: (fn FUNCTION SEQUENCE)

*** ~-join~ =(&rest lists)=

: (fn &rest LISTS)

*** ~-append~ =(&rest sequences)=

Concatenate all the arguments and make the result a list. The result is a list whose elements are the elements of all the arguments. Each argument may be a list, vector or string.

All arguments except the last argument are copied.  The last argument is just used as the tail of the new list.  If the last argument is not a list, this results in a dotted list.

As an exception, if all the arguments except the last are nil, and the last argument is not a list, the return value is that last argument unaltered, not a list.

*** ~-strings~ =(&rest input)=

Return INPUT as a flat list, optionally coercing non-string elements. A trailing ‘:options OPT’ pair in INPUT selects how non-strings are handled: ‘filter’ drops them, ‘stringify’ formats them with ‘format’. OPT may be a list combining these symbols. *** ~-map-in-place~ =(mapper items)=

*** ~--map-in-place~ =(form items)=

This is the anaphoric counterpart to ‘-map-in-place’.

*** ~-in-place~ =(mapper items)=

Destructively apply MAPPER to every item in ITEMS, replacing each element in place. Returns the count of elements processed. Use this when you need the element count rather than the list itself; prefer ‘-map-in-place’ when you need the modified list back.

*** ~--in-place~ =(form items)=

*** ~add-one-shot-hook~ =(&rest --cl-rest--)=

Register a self-removing hook function named NAME on HOOK. The hook body is specified via one of: FUNCTION (a symbol or lambda), FORM (an expression), BODY (a list of forms), RESULT (evaluated at expansion time), or OPERATION (called via funcall/apply with optional ARGS).

After firing COUNT times (default 1) the hook removes itself. Set PERSIST to t to keep the hook active indefinitely. When IDLE-TIMER is a number, the body runs in an idle timer of that many seconds rather than directly in the hook.
